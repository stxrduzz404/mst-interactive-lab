# MST 佈線研究所

以 Kruskal 與 Prim 演算法為主題的最小生成樹（Minimum Spanning Tree, MST）互動教學網站。使用者可以逐步播放演算法，直接觀察邊的選取、成環淘汰、併查集、優先佇列、目前總重與對應虛擬碼。

## 網站功能

- Kruskal 逐步演示：排序、`find`、成環判斷、`union`、收邊與完成條件。
- Prim 逐步演示：起點、Min-Heap 候選票、取出最小票、舊票淘汰與向外擴張。
- 三組圖形情境：一般連通圖、同權重平手圖、不連通圖。
- Prim 可自由更換起點，驗證起點不影響 MST 最小總重。
- SVG 即時圖形：橘色表示檢查中、綠色表示已收下、紅色虛線表示淘汰。
- 資料結構同步顯示：Kruskal 顯示排序邊與 `parent[]`；Prim 顯示優先佇列與 `inTree[]`。
- 上一步、下一步、自動播放、時間軸跳轉及鍵盤操作。
- 虛擬碼逐行高亮，對照目前演算法步驟。
- 三題觀念測驗與即時解說。
- 支援桌面、平板與手機版面。

## 程式流程

### 1. 圖形資料

`js/data.js` 保存頂點座標與邊。每條邊進入演算法前會正規化成：

```js
{ id: "e0", u: 0, v: 1, w: 4 }
```

- `u`、`v`：邊的兩端。
- `w`：權重。
- `id`：提供 SVG 與演算法步驟共同識別同一條邊。

### 2. 先算完，再播放

`js/mst-core.js` 不直接操作畫面。演算法執行時，每個重要動作都存成一份 step 快照：

```js
{
  kind: "take",
  title: "收下 B–C",
  selected: ["e2"],
  rejected: [],
  total: 1,
  current: "e2",
  line: 7
}
```

畫面只負責顯示 `steps[目前索引]`。因此上一步不需要反向拆除併查集或還原優先佇列，只要把索引減一即可，狀態較容易驗證。

### 3. 畫面更新

`js/app.js` 的 `render()` 依目前 step 更新五個區域：

1. SVG 邊與頂點狀態。
2. 排序邊／優先佇列。
3. `parent[]`／`inTree[]`。
4. 統計、步驟標題與白話說明。
5. 對應虛擬碼高亮行。

使用者切換演算法、情境或 Prim 起點時，系統會重新建立 steps，再從第 0 步開始。

## 演算法說明

### Kruskal

1. 依 `(權重, u, v)` 將所有邊由小到大排序。
2. 每個頂點先各自成為一組：`parent[x] = x`。
3. 依序取邊 `(u, v, w)`，計算 `find(u)` 與 `find(v)`。
4. 代表相同：兩端原本已連通，加入會成環，因此跳過。
5. 代表不同：合併兩組、收下此邊並累加權重。
6. 連通圖收滿 `V−1` 條邊後完成。

排序需要 `O(E log E)`；路徑壓縮後的併查集操作接近常數時間。整體時間複雜度為 `O(E log E)`，額外空間為 `O(V + E)`。

### Prim（Min-Heap 版）

1. 將起點票 `(0, start, none)` 放入 Min-Heap。
2. 每次取出權重最小的 `(w, v, from)`。
3. 若 `v` 已在樹中，該票已失效，直接丟棄。
4. 否則以 `from–v` 將 `v` 加入樹中，總重增加 `w`。
5. 將 `v` 連向尚未進樹頂點的邊放入 Min-Heap。
6. 佇列清空即完成；不連通圖會從未造訪頂點重新啟動，形成最小生成森林。

每條邊至多進出 Heap，時間複雜度為 `O(E log V)`，額外空間為 `O(V + E)`。

## Kruskal 與 Prim 比較

| 項目 | Kruskal | Prim |
|---|---|---|
| 貪心視角 | 全圖最便宜的未處理邊 | 目前樹往外最便宜的邊 |
| 核心資料結構 | 排序＋Union-Find | 鄰接表＋Min-Heap |
| 成環處理 | 兩端同組就跳過 | 目的頂點已進樹就丟棄舊票 |
| 時間複雜度 | `O(E log E)` | `O(E log V)` |
| 不連通圖 | 自然得到最小生成森林 | 每個元件需要重新選起點 |

兩者都建立在切割性質上：對任意頂點切割，跨越兩側的最小權重邊是安全邊。權重平手時，可能得到不同的 MST，但最小總重相同。

## 本機執行

本專案是原生靜態網站，不需要安裝前端套件。

### 方法一：VS Code Live Server

1. 用 VS Code 開啟專案資料夾。
2. 安裝 Live Server 擴充套件。
3. 在 `index.html` 按右鍵，選擇 **Open with Live Server**。

### 方法二：Python

```bash
python -m http.server 5173
```

瀏覽器開啟 `http://localhost:5173`。

> 不建議直接雙擊 `index.html`。網站使用 ES Modules，部分瀏覽器會阻擋 `file://` 載入模組；透過本機伺服器即可正常執行。

## 測試

需安裝 Node.js 18 以上版本，再於專案根目錄執行：

```bash
npm test
```

目前測試涵蓋：

1. 校園圖的 Kruskal 與 Prim 都得到總重 13。
2. Kruskal 正確淘汰會形成環的 A–B 邊。
3. Prim 從不同頂點出發仍得到相同最小總重。
4. 不連通圖正確得到兩棵樹、四條邊、總重 8 的最小生成森林。
5. 同權重圖仍產生合法的 `V−1` 條最小生成樹。

## 鍵盤操作

| 按鍵 | 功能 |
|---|---|
| `←` | 上一步 |
| `→` | 下一步 |
| `Space` | 自動播放／暫停 |

當游標停在按鈕、下拉選單或時間軸時，不會攔截鍵盤輸入。

## 技術選擇

- 原生 HTML：保留清楚的語意結構，方便課堂檢查。
- 原生 CSS：使用 Grid、Flexbox、CSS 變數與響應式斷點。
- 原生 JavaScript ES Modules：演算法、資料與畫面分層，無框架綁定。
- SVG：邊、權重與頂點可依 step 狀態直接更新 class，不需圖片素材。
- Node.js 內建測試器：不安裝額外測試框架即可驗證核心演算法。
